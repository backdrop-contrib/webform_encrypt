Webform Encrypt will encrypt or decrypt previously encrypted webform components (fields).
Ported from Drupal webform_encrypt 7.x-1.3

Requirements
------------
<!--
List any dependencies here. Remove this section if not needed.
-->

This module requires that the following modules are also enabled:

- [Encrypt](https://github.com/backdrop-contrib/encrypt)
- [Webform](https://github.com/backdrop-contrib/webform)
